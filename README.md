# OpenBridge AI

An offline AI assistant designed for seafarers.

> Reduce paperwork.  
> Reduce repetitive tasks.  
> Let seafarers focus on navigation and engineering.

---

## Introduction

OpenBridge AI is an experimental open-source project created by a maritime student.

The goal is simple:

Build a lightweight offline AI assistant for ship officers and engineers.

Instead of replacing seafarers, OpenBridge AI aims to help with:

- Logbook writing
- Shift handover summaries
- Maintenance records
- PSC preparation
- Maritime English assistance
- Daily task reminders
- SMS / checklist queries

Designed for real ship environments:

- Limited internet
- Expensive satellite connections
- Small onboard networks
- High paperwork pressure

---

## Why This Project Exists

Modern ships are becoming increasingly intelligent.

But many seafarers still spend large amounts of time on:

- Repetitive paperwork
- Manual reports
- Email writing
- Searching PDFs
- PSC document preparation

This project focuses on:

> AI for seafarers, not AI replacing seafarers.

---

# 中文介绍

OpenBridge AI 是一个面向船员的离线 AI 助手开源项目。

项目目标并不是“无人船”，而是：

> 减少船员重复文书工作，  
> 让船员把更多精力放在航行与设备管理上。

---

## 为什么做这个项目？

现代船舶越来越智能。

但很多船员每天仍然需要花费大量时间处理：

- 航海日志
- 检查表
- PSC 文书
- 英文邮件
- 设备记录
- 交班内容
- SMS 文件查询

尤其在远洋环境下：

- 网络昂贵
- 卫星通信有限
- 文件繁杂
- 值班疲劳严重

因此本项目希望尝试：

# “离线 AI + 船员工作流”

而不是单纯追求“无人化”。
